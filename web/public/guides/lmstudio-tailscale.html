Use LM Studio on your phone

Your PC runs the AI model. Tailscale gives it a private, secure https address that only your devices can reach, at home or away. Baller Buddy on your phone talks to that address.

  1. Get LM Studio ready

    On the PC

    Open LM Studio and go to the Developer tab (the >_ icon on the left).

    • Click Server Settings and turn on Enable CORS. This lets a web app talk to it.
    • Make sure the status switch at the top says Running.
    • Load a model: click Select a model to load at the top and pick one. Your screenshot showed none loaded, and nothing answers without one.

    Leave the port at 1234. The rest of this guide assumes it.

  2. Install Tailscale on the PC

    On the PC
    • Go to tailscale.com/download and download the Windows version.
    • Install it, then click Log in and create your free account (Google, Microsoft or Apple sign-in is easiest).
    • A Tailscale icon appears in the system tray, near the clock. That means it's on.

  3. Install Tailscale on the phone

    On the phone
    • Get Tailscale from the Play Store (Android) or App Store (iPhone/iPad).
    • Sign in with the same account you used on the PC.
    • Turn it on. When the phone asks to allow a VPN connection, tap Allow / OK.

    In the Tailscale app you should now see your PC listed as a device.

    Tailscale only routes traffic to your own devices, so your normal browsing and apps are unaffected.

  4. Give LM Studio an https address

    On the PC

    Press Start, type cmd, and open Command Prompt (PowerShell works too). Paste this and press Enter:

    > tailscale serve --bg 1234

    If it prints a link saying Serve or HTTPS isn't enabled: open that link, click Enable, then run the same command again.

    When it works it prints an address like this. Copy it; you'll need it next.

    https://my-pc.tail1234.ts.net

    --bg keeps it running in the background, even after you close the window or restart the PC. You only do this once.

  5. Point Baller Buddy at it

    On the phone

    Paste the address from step 4 here to get the exact one to enter:

    Paste it above and the address to use appears below.
    https://my-pc.tail1234.ts.net/v1
    • In Baller Buddy open Settings›AI Providers and find the LM Studio card (not Custom).
    • Replace the address with the one above, ending in /v1. It saves when you tap away from the box.
    • Tap Test. If Chrome asks to let the site access devices on your local network, tap Allow.
    • Set LM Studio as your default model, then ask the AI Analyst something.

Every day after this

It works anywhere

Home Wi-Fi, mobile data, a friend's place. As long as:

  • The PC is on and awake
  • LM Studio is running with a model loaded
  • Tailscale is on on the phone

On the PC itself

Using Baller Buddy in the PC's browser? You don't need Tailscale there. The default address works:

http://localhost:1234/v1

If the Test fails

"Failed to fetch" or "Network error"

Usually CORS is off in LM Studio. Check Developer › Server Settings › Enable CORS (step 1).

Also check Tailscale is on on the phone. The Tailscale app should say Connected.

It connects but there's no answer, or "no model"

No model is loaded. In LM Studio pick one from "Select a model to load" at the top. Models unload when LM Studio closes.

404 or "Not found"

The address should end in exactly /v1: not missing, and not /v1/v1. Use the builder in step 5.

The address doesn't load at all

Check that serve is still on. On the PC run:

> tailscale serve status

If it shows nothing, run tailscale serve --bg 1234 again.

It worked yesterday but not today

The PC may be asleep. Set Windows' Sleep to "Never" while plugged in (Settings › System › Power), or wake it before using AI from your phone.

Why is this needed?

Baller Buddy is now a web app served over https (secure). Browsers block secure pages from calling plain http addresses like http://192.168.1.76:1234. This is called mixed content, and there's no setting to turn it off.

Browsers also ask a server for permission before a web page can talk to it. That's CORS, which is why LM Studio needs it switched on.

The old Android app was a native app, and these browser rules don't apply to native apps. Tailscale fixes both: a real https address, private to your devices, and it works away from home too.
